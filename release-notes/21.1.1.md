The formatter's output is the same as 21.1.0's, so this release needs no reformatting run. It fixes two failures in the IntelliJ IDEA plugin.

## IntelliJ IDEA plugin

- Reformat Code no longer fails with "Error running the native image command" when **Run the formatter** is set to **Native binary** or **In a separate JVM**. IntelliJ IDEA can pass an empty range among the ranges it reformats, and the formatter's command line rejected it with "Invalid range" ([#275](https://github.com/openjavaformat/open-java-format/issues/275), [#277](https://github.com/openjavaformat/open-java-format/pull/277)).
- The settings page no longer fails with a `ClassCastException` when palantir-java-format is installed too. Both plugins register a service under the same class name, `PalantirJavaFormatSettings`, and the IDE keys a service by its class name. The plugin now declares itself incompatible with palantir-java-format, so the IDE never loads the two together; to keep open-java-format, disable palantir-java-format ([#276](https://github.com/openjavaformat/open-java-format/issues/276), [#278](https://github.com/openjavaformat/open-java-format/pull/278)).

## Command line and build plugins

- With the native binary or a separate JVM, `formatDiff` no longer reformats the whole file when a diff adds only blank lines ([#277](https://github.com/openjavaformat/open-java-format/pull/277)).
